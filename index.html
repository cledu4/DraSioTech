Drasiotech : Innovation & Pédagogie Numérique

Bienvenue sur la plateforme officielle du projet Drasiotech. Ce site vitrine a pour vocation de démontrer les compétences techniques acquises en BTS SIO (Services Informatiques aux Organisations), options SISR et SLAM.

Nos Objectifs Techniques (SEO & Web)

Contrairement aux solutions complexes, Drasiotech.fr mise sur la performance pure et la sémantique HTML5. Notre défi : prouver qu'un code propre et léger surpasse les frameworks lourds en référencement naturel.

  • 🚀 Performance : Temps de chargement optimisé (Core Web Vitals).
  • 🔍 SEO White Hat : Structure sémantique respectant les standards W3C.
  • 📱 Accessibilité : Design responsive et lisible sur tous supports.

Pôle de Compétences SISR (Infrastructure)

Réseau Système Sécurité

Dans le cadre de l'option Solutions d'Infrastructure, Systèmes et Réseaux, le projet Drasiotech explore :

  • L'administration de serveurs Windows Server et environnements Linux.
  • La virtualisation d'infrastructures via VMware et conteneurisation Docker.
  • La mise en place de politiques de cybersécurité et de plans de continuité d'activité.

Pôle de Compétences SLAM (Développement)

Web Mobile DevOps

L'option Solutions Logicielles et Applications Métiers de Drasiotech se concentre sur :

  • Le développement web full-stack (HTML5, CSS3, JavaScript, PHP).
  • L'intégration continue et le déploiement sur des plateformes modernes comme Vercel.
  • La gestion de bases de données relationnelles (MySQL, PostgreSQL) pour les applications métiers.
