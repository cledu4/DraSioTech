À Propos de Ce Projet

Contexte Pédagogique

Drasiotech est un projet réalisé dans le cadre de la formation BTS Services Informatiques aux Organisations (SIO). Ce site web a été conçu par un groupe de 4 étudiants avec des objectifs pédagogiques précis et ambitieux.

Validation des Blocs de Compétences

Ce projet valide les blocs de compétences essentiels du diplôme Services Informatiques aux Organisations :

Conception et Développement d'Applications

Création d'une interface web responsive et accessible. Utilisation de HTML5 et CSS3 pour un code sémantique et performant. Structure multi-pages optimisée pour le référencement naturel (SEO).

Cybersécurité des Services Informatiques

Mise en place de protocoles sécurisés et code épuré sans failles. Aucune surface d'attaque : site 100% statique HTML/CSS sans JavaScript. Protection contre les injections, XSS et autres vulnérabilités web. Veille technologique sur les meilleures pratiques de sécurité.

Intégration et Adaptation de Services

Déploiement continu (CI/CD) depuis GitHub vers l'environnement de production Vercel. Automatisation du workflow de développement. Gestion de version avec Git et collaboration en équipe.

L'Objectif : Top 1 Google

Le défi principal de ce projet est d'atteindre la première position sur Google pour la recherche "drasiotech". La compétition est rude entre les différents groupes d'étudiants.

Notre Stratégie SEO

Top-Level Domain (.fr)

Face à des solutions basées sur des sous-domaines génériques, Drasiotech se distingue par l'utilisation d'un nom de domaine en .fr (drasiotech.fr), offrant une meilleure crédibilité et un meilleur référencement local.

Stratégie "White Hat" SEO

Respect strict des dernières directives Core Web Vitals de Google. Optimisation technique : structure sémantique, balises meta, sitemap XML, robots.txt. Contenu de qualité et pertinent axé sur les thématiques SISR et SLAM. Aucune technique de spam ou de manipulation des résultats.

Expérience Utilisateur (UX)

L'optimisation du Dwell Time (temps passé sur le site) est au cœur de notre stratégie de classement. Navigation intuitive et contenu structuré sur plusieurs pages. Design responsive pour une expérience optimale sur tous les appareils. Performance optimale : chargement rapide et code léger.

Architecture Multi-Pages

Structure en 4 pages distinctes pour maximiser le référencement : page d'accueil pour la présentation globale, page SISR dédiée aux services d'infrastructure, page SLAM pour le développement d'applications, page Contact avec contexte du projet. Chaque page est optimisée pour des mots-clés spécifiques liés à Drasiotech.

Sécurité et Résilience

Un étudiant autorisé du cours effectue des tests de sécurité sur les sites concurrents. Drasiotech a été conçu pour résister à ces attaques :

  • Code 100% statique sans JavaScript (aucune exécution côté client)
  • Aucun formulaire ou point d'entrée utilisateur
  • Validation HTML5 et CSS3 stricte
  • Headers de sécurité configurés via Vercel
  • Aucune dépendance externe vulnérable

Technologies Utilisées

Frontend

HTML5 sémantique, CSS3 moderne avec Flexbox et Grid, Design responsive (mobile-first)

Hébergement et Déploiement

Vercel pour l'hébergement et le déploiement automatique, GitHub pour la gestion de version et la collaboration, CI/CD automatisé pour des mises à jour rapides et sécurisées

SEO et Performance

Google Search Console pour l'indexation, Sitemap.xml et robots.txt optimisés, Balises meta et structure Open Graph, Optimisation Core Web Vitals
